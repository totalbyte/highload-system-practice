# 2026-11-04 — Participant 1 — Web UI
**Lab:** — (after lab 5) · **Commits:** not committed (branch `feature/web-ui`)
## Goal
A user-facing web UI styled after a public e-petitions registry, covering the existing functionality plus a small new
feature (favorites).
## Done
- `frontend/`: React 19 + Vite 7 + TypeScript, React Router 7, TanStack Query 5, hand-written CSS (blue / yellow,
  white cards, responsive with a burger menu). Pages: home (hero with counters, tabs active / closed / all, pagination,
  cards with number, author, date, vote counter and leading option), poll page (radio options with result bars, vote /
  change vote, auto-refresh 5 s while open, "your choice", `X-Instance-ID` + `X-Cache` badge, author actions), create
  poll (2–20 options, dates, public / vote change / publish now, 422 field errors), login / register, my polls,
  favorites, 404.
- Favorites: localStorage (`polling:favorites`), synced across tabs.
- Backend: `GET /api/polls/{id}/vote` (`VoteService.GetMyVoteAsync`, `VoteNotFoundException` → 404).
- Docker: `frontend/Dockerfile` (node build → nginx), `frontend/nginx.conf` (SPA fallback, immutable `/assets`),
  service `web` in compose; HAProxy `be_web` for everything except `/api/`, `/swagger`, `/health`.
- Docs: ADR 0048, contracts, runbook «Web UI», README structure, root CLAUDE.md quick-start line.
## Decisions (link ADRs)
- [0048](../decisions/0048-web-ui.md): React SPA behind the same HAProxy, favorites in localStorage, my-vote endpoint.
## Problems & fixes
- Page stuck on «Завантаження…» while all API calls returned 200: `AuthProvider` called `removeQueries` on mount
  (StrictMode runs effects twice), dropping queries that components were observing. Now it resets only when the token
  really changes, with `resetQueries` (refetches active ones).
- Header wrapped at ~800 px once logged in → no-wrap nav, hide logo subtitle < 1100 px, burger menu < 920 px.
